# React E-Commerce Task

A modern React e-commerce frontend built using React + Tailwind CSS.

## Features
- Shops
- Become a Seller
- Add to Cart
- Search & Filter
- Responsive Design
- Modern UI

## Tech Stack
- React
- Tailwind CSS
- Context API

## Installation

```bash
npm install
npm run dev
```
